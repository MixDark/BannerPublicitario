# MIX DARK DEV — Banner Publicitario · Space Edition

Banner publicitario animado con temática espacial, construido con HTML, CSS y JavaScript puro.

## Características

- Fondo animado tipo **warp star field** (campo de estrellas con efecto de viaje espacial) renderizado en Canvas 2D.
- **Nebulosas CSS** animadas mediante filtros y gradientes radiales.
- Estilos con **Tailwind CSS** (CDN) y fuentes **Orbitron** + **Share Tech Mono** de Google Fonts.
- Variables CSS personalizadas para colores neón (cian, púrpura, rosa).
- Diseño totalmente responsivo y centrado.
- Sin dependencias de build — se ejecuta directamente en el navegador.

## Estructura del proyecto

```
BannerPublicitario/
├── index.html   # Estructura principal y configuración de Tailwind
├── main.js      # Lógica de animación (Canvas, estrellas, efectos)
├── style.css    # Estilos globales, nebulosas y animaciones CSS
├── README.md
├── CHANGELOG.md
└── .gitignore
```

## Uso

1. Clona o descarga el repositorio.
2. Abre `index.html` directamente en el navegador (no requiere servidor).

```bash
# Opcionalmente, con Live Server de VS Code:
# Clic derecho sobre index.html → "Open with Live Server"
```
